# Original MATLAB code

The original code of the thesis project, unchanged (files dated February-March 2021, thesis defended 3 March 2021). Entry point: `myfilter.m`
(needs MATLAB with the Image Processing Toolbox; it asks for the cars on the
command line, see `inputcar.m`).

`example_output/` holds files written by one run (`inf2.mat` = input cars,
`inf.mat` = final state, `frame.jpg` = last frame). The Python port is checked
against the trajectories in `inf.mat`.
